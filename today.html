오늘 한 장

열기 → 오늘 → 닫기. 틀린 줄만 답하면 됩니다.

지금 여는 칸 — 타임라인

한 변수 = 열기 Prediction → 오늘 판정 → 닫기 Actual
  1. 1. 열기어제 Prediction · 어제 Actual을 받는다. Hypothesis. Next test = 오늘 변수. 오늘 Prediction을 적는다.
  2. 2. 오늘판정 · 말 · 영상. 오늘 변수 하나.
  3. 3. 닫기오늘 Actual을 적는다. Exit · 글 · 주인.
  4. 4. 다음 열기오늘 Prediction → 어제 Prediction. 오늘 Actual → 어제 Actual.

관찰 사실과 작업가설을 분리한다. Actual을 열기에 다시 쓰지 않는다. Prediction과 Actual을 한 줄로 강제하지 않는다.
