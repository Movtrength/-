순환

열기 → 오늘 → 닫기 → 열기

한 변수 = 열기 Prediction → 오늘 판정 → 닫기 Actual

1. 열기

어제 Prediction · 어제 Actual. Hypothesis. Next test. 오늘 Prediction.

2. 오늘

판정 · 말 · 영상. 오늘 변수 하나.

3. 닫기

오늘 Actual. Exit · 글. 주인 하나를 넣지 않는다.

4. 다음 열기

오늘 Prediction → 어제 Prediction. 오늘 Actual → 어제 Actual.

닫기의 주인 하나(공유 · 업로드)는 뺀다. 오늘 끝은 영상 · 만족. 누적 칸으로 오늘을 닫지 않는다.
